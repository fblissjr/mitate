The session read the whole tree cold (VISION, the router, the working plan's

# Second part — what changed under the frame

Under the owner's frame the ranking changed in one concrete way: the CLI on
this machine supports `--plugin-dir` and stream-JSON print mode, so the
cold build — the second flywheel's only instrument, blocked for four weeks
on an owner step — can be a script. The session explained the mechanics,
the risks, the case for and the case against before building anything; the
owner said go, and created an empty folder outside the repo for the runs.

One finding the owner asked about, "how does it know what to learn, and
what to simplify or remove": today it does not; a person notices. A
one-minute census of kernel exports against the corpus (definition counts
subtracted; the commands are in `docs/harness-loop.md`'s board section)

kit, `latch` and `quant` by one film each, and `bear-and-bees` defining its
own `rampS` beside them. The `STYLE.dof` shape of 0.23.0 again. That became
step 2 of the plan (a derived corpus census, with those two names as its

# Fifth part — the owner's question closes a hole

The owner made the cold-build folder a git repo with a remote on the LAN,
then asked the right question: if the session is pointed at `plugin/`
inside the checkout, does it get the checkout? Yes — nothing stopped it
walking up from its skill directory into `docs/`, which a marketplace
install cannot do, so the working-tree run was leakier than the fixture it
stands in for and the contamination check only caught it afterwards. The
script now copies `plugin/` into the run directory and loads the copy (the
copy's parent holds nothing), treats a read of the in-place `plugin/` as
contamination, refuses a cold root with a `CLAUDE.md` or `AGENTS.md`
anywhere in its ancestry (the cold root being a repo makes that a live
hazard), and records the workspace's git root in the manifest. Two new
bracket arms. A stray quote from the patch broke the script's syntax and
turned every arm red at once before the arms could mean anything; fixed,
all arms green, selfcheck green. Committed as `5c2eb66`; this note and the
plan's step-1 wording landed in the commit after it, because the doc patch
failed on a whitespace anchor and the commit went ahead without it.
