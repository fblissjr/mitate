# 2026-11-08 — mitate v2 (Slate) branch, updated VISION.md, and architecture roadmap

The owner initiated the `v2` branch to plan `mitate` v2, combining `mitate`'s core philosophy (`t` as a random-access coordinate, relative beat addressing, declarative cinematography/shots/characters, Tier-1 bake-time simulation, and the three-axis review loop) with the **Slate** specification: an agent-first SQLite 3 Virtual Soundstage (`shot.db`) backed by a native Swift 6 + Metal 3/4 renderer on Apple Silicon.

# Key decisions confirmed with the owner

1. **Prime Directive preserved (`t` as a random-access coordinate)**:
   - Closed-form kinematics remain the default (`kinematics(t, state)`).
   - Multi-agent swarms, collisions, and stateful physics use an explicit build-time bake (`mitate bake shot.db --seed <N>`) that writes deterministic trajectories into SQLite (`baked_tracks`), keeping `seekTo(t)` strictly $O(1)$ random-access with zero cross-frame runtime state.
   - Temporal history buffers (`MTLFXTemporalScaler`) are omitted from the core evaluation pipeline in favor of spatial `MTLFXSpatialScaler` + single-frame AOV-guided wavelet denoising (`Denoise.metal`) so evaluating frame `t` never depends on frame `t-1`.
2. **Primary artifact & delivery**:
   - The portable SQLite 3 database (`shot.db` / `.mitate`) is the canonical source artifact for v2.
   - Native Metal renders (`.mp4`, `.mov` ProRes 4444, `.png`, `.jpg` contact sheets/quads/strips) are the primary visual outputs, alongside an optional self-contained WebGPU/three.js HTML exporter (`mitate bundle shot.db --out scene.html`) honoring the `window.seekTo(t)` contract.
3. **Unified SQLite schema**:
   - `shot.db` carries both `mitate`'s higher-level declarative intent tables (`beats`, `style_bibles`, `sizes`, `characters`, `subjects` with `auto_bounds = 1`, `shots`, `warp_segments`, `baked_tracks`) and Slate's physical soundstage tables (`slate`, `actors`, `props`, `surface_shaders`, `lenses`, `lamps`, `atmospheres`, `swarms`, `gpu_kernels`, `state_buffers`, `cue_sheet`, `finishing_chain`, `takes`, `media_bay`).
4. **Zero fragile external daemon dependencies**:
   - Built as a self-contained Swift 6 + Metal binary (`mitate`, aliased as `slate`) with built-in parametric CSG/SDF/procedural explainer geometry (`gear`, `ring`, `arrow3d`, `text3d`), situated JSON telemetry on stdout, and progressive CLI disclosure (`mitate schema`, `mitate recipe`).
