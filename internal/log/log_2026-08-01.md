## Four things refuted by running them

None was found by reading. All four looked obviously right when proposed, and
**all four were fixes, not defects** — which is the part worth carrying.

1. **The cascade check's first anchor** (merge-base with `origin/main`) —
   **exit 0 on the live violation.** An early bump satisfies a whole-branch
   delta forever. Proposed in the same breath as the rule against decorative
   controls.
2. **The same check, second cut** — compared committed history only, so it could
   never go green in the commit that fixes it. The hook blocks until the bump is
   committed; committing is what the hook blocks.
3. **The same check, third cut** — diffed `anchor..HEAD`, firing one commit
   *after* the violation. Found while writing the bracket, not while writing the
   check.
4. **Mandatory capture fields in commit messages** — the guard's own commit
   already contains a voluntary rejected-alternatives passage. The field would
   have been satisfied and the guard would still be unexplained. Granularity
   mismatch: commits are the wrong unit for a fifteen-character sub-expression.

Also refuted: **deriving check order from `requires`/`provides`** — zero edges,
because no check writes to `ctx`.
