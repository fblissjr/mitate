# 2026-09-10 — a timeline film from a git record, and what it put back into the kit

The session's main work was elsewhere: a sibling research project asking
whether an agent coding session can be made reviewable, using one day of
another project's multi-session git history as a pretend PR `(local)`. mitate
entered twice. First as a question the owner posed — could mitate replay a
session for a reviewer — answered in that project's vision as "borrow the
model (position-addressed state, declarations over prose, a thin contract,
the actor's account is a lead and the record is the evidence), not the
renderer". Then as a film, because the owner asked for one.

# The film

A 40s Canvas2D film of one contested hour of that history `(local)`, kept
outside this repo because it carries session names, hashes and commit
subjects. Five session lanes, a lane for events no transcript recorded, local
and origin rails, and a record clock that slows at three moments: one
session's file edit swept into another's commit, a published commit amended
twice, and a force-push that left it on no branch. Every event came from the
reflog or a transcript.

Built from the working tree's `plugin/` copy (scene2d template), with full
repo context — so it is an instance for the ledger and **not** cold-build
evidence. `check` 0 errors after one warn (an unused `STYLE.stroke` it
correctly flagged), two `sheet` rounds, one `nocap` sheet, two `strip` passes,
`smoke.js` all pass with 168 fenced lines byte-identical to the store.

Composition round one found three defects, all fixed in round two: zoomed
keys clipped the origin tag and slid a whole lane under the caption band;
hash labels on adjacent commits collided; a review label sat on a rail. The
first `strip` was aimed by hand and ended just as the motion it was meant to
cover began — the second strip, aimed from the event's computed `t`, showed
smooth motion with no pops.

The `nocap` pass: geometry alone carries "something was rewritten" (nodes
lift off the rail, the pointer turns red, a red arrow marks the force-push);
it does not carry identity, and the push no transcript recorded reads as a
grey mark. Another data point for method.md's observation that labelled
geometry carries a diagrammatic film.

# What went back into the kit (0.29.0)

The field report named two re-derivations, and the owner confirmed both
belong on the ledger and in the shipped skill:

- **Screen-anchored drawing under a moving 2D camera** — counted 2, because
  `scenes/crash.html` had already built `CAM` plus `worldToScreen`, and this
  film rebuilt it without reading that file. Promoted into the 2D template.
- **Event clock to scene position** — counted 1 (no earlier instance found by
  grep across the corpus and templates). Shipped as a tested snippet in
  `method.md` by owner call, with the kit helper still waiting on a second
  instance.

Plus one framing rule with no instrument behind it: a push-in carries
geometry under the caption band. smoke checks caption overflow and reading
speed, not occlusion.

# Second part: 0.30.0, the instruments the film was missing

The owner asked for the improvements the session had listed. Four landed:

- `build.js band`, ink under the caption on 2D scenes, with
  `bracket-band.js`. Red first: all four arms failed before the verb
  existed, then passed (pristine 0%, content pushed under the pill 80.6%,
  both declared skips). No threshold, by design: one observed bad case and
  one fine case bracket nothing a threshold could rest on.
- `strip` bounds as `beat@fraction`, resolved statically through the
  KERNEL. The first idea was arbitrary expressions (so `tAt(c)` could aim a
  strip directly); rejected because selfcheck check 6f holds the prime
  directive's exception to `probe` alone, single call site. The reference
  now routes record times through `probe`.
- `bracket-camera2d.js`, the control 0.29.0's `worldToScreen` shipped
  without. Its first run failed its own pristine arm: a 1e-6 px tolerance
  against `DOMMatrix` float error of 2.5e-5 px. The mutants miss by about
  604 px, so the tolerance moved to 1e-3 px; a bracket defect, recorded
  because it looks like tuning and is not.
- A cold brief with a timestamped record as input, not yet run.

`bracket-commands.js`: 44 rows as specified after the additions.

# Third part: the film's v2, and band's first real reading

A v2 of the timeline film `(local)`, built from the installed 0.30.0 copy.
`band` on the first version read 6.0-8.0% on its five zoomed beats and 0.0%
on the two unzoomed ones: the round-two layout fix had moved the lanes and
left a label row in the band, which the contact sheet had shown and the
reviewer (this session) had not registered. v2 clips the world pass above
the band and reads 0.0% on all seven, uses the template's `worldToScreen`,
and aims its strip as `sweep@.5 sweep@.75`. The new shape, a caption-safe
clip, went on the ledger at one instance. smoke raised one exposure advisory
on v2 (low dynamic range, provisional threshold) that v1 did not; judged by
looking, not chased.

Not promoted, recorded here only: the film was a first exercise of "any
input" with a dataset as the input (a warehouse query became the event
table), the data-as-code direction VISION argues, and the field-report step
was followed in full form — by a builder with repo context, so it grades
nothing about the step's reach.
