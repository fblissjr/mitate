**Verification takes TWO dispatches, and two earlier versions of this log got that
wrong.** It said `no_canvas: true` must return 0/200. It cannot: `--no-canvas`
bypasses `seekSynced` by construction, so it was never able to test the fix. The
sampler had two modes and neither exercised the shipped path — corrected
2026-07-30 so the default now calls `seekSynced`. The protocol:

```
gh workflow run sample-determinism --ref main -f repeats=10                      # shipped path: must be 0 failures
gh workflow run sample-determinism --ref main -f repeats=10 -f no_canvas=true    # control: must STILL fail
```

Both arms are needed. A clean shipped run proves nothing if the control arm has
also gone quiet — that would mean the instrument stopped detecting the race.
Last control measurement (run 30514669527, pre-fix pattern): materials@5.36 8/10,
menagerie@8.52 4/10, menagerie@5.68 2/10. Note the rate swings hard — the same
cell measured 40% an hour earlier — which is itself evidence of a timing race.

Measured, not inferred (run 30513771889 vs 30513335626, both 10 repeats,

| mode | result |
|---|---|

The readback is the only variable and it eliminates the failure. A real state

**Do not repair this by touching the determinism arm** — bake proposal red line

poll for a presented frame rather than counting two rAFs; or wait on an in-page
readback (which is precisely what suppressed the failure, so it is known to work
and its cost is one GPU sync per capture).

**Reproduce before and after** with the instrument that found it:

The fix is proven when that run is 0/200 with `--no-canvas`. Anything less and

## Standing traps, learned by falling in

- **Never pipe a validator into `tail`/`grep`.** The pipeline reports the filter's
  status; a red self-check read as green and got committed through.
- **`git status` on the remote before amending.** Amended a pushed commit; fixed
  with `reset --soft origin/main`, no history rewritten.
- **N-of-N is evidence of N, not of determinism.** Three identical failures were
  published as "reproducible, a state dependency"; run four refuted it.
- **An instrument that adds a synchronization point cannot measure a race.** The
  first sampler read the canvas and hid the very failure it was built to find.
- **Writing a rule in a comment is not implementing it.** Twice: 0.16.9's anchor,
  and my own sampler printing `SCENE STATE (canvas differed)` in a mode where the
  canvas is never read, with a comment above it forbidding exactly that.
