# 2026-08-05 — the cold session comes home: mining market-crash, shipping 0.19.4

The owner pointed this session at the artifacts of the 2026-08-04 cold-start
build — the market-crash film built in an isolated workspace outside this
repo, by a sonnet-5 session running only the installed plugin (0.19.3, which
was byte-identical to the working tree at the time, so it exercised exactly
what ships). Evidence base, all local and untracked: the scene and its two
postmortems under the local fixture directory, the transcript index at
a local transcript database, and the raw session transcript in a local
directory. One caveat on the window: thinking blocks in the raw transcript are stored
empty (redacted), so the behavioral evidence is the session's visible
narration plus its tool calls — 46 thinking blocks exist and none is
readable.

## What the transcript shows (derived, this session, from the db)

- Prompt to delivered MP4 in ~18 minutes (19:32:08 → 19:50:28), 96 tool
  calls, **zero tool errors**, zero user interventions between prompt and
  delivery. `total_tool_errors = 0` from `semantic_sessions`.
- The session read exactly two references — `method.md`, `bibles.md` — plus
  the 2D template before writing the whole scene, and **opened no example
  scene at any point** (every Read in the db is accounted for: the scene
  itself, build.js, the instrument output images). That is
  examples-placement's settling experiment, effectively run: examples were
  in the cache and did zero teaching for the 2D register.
- Its task list mirrored the documented loop exactly (check → composition →
  continuity → semantics → smoke/deliver), unprompted.
- The instruments caught two real defects pre-delivery: `sheet` a duplicated
  HUD readout at the halt; `motion` the halt beat as the film's
  highest-motion beat (10.73 vs 5.20 next) — backwards for a freeze — fixed
  to 7.40 with a measured dead-air hold (t=32.00–34.17s, 44% of the beat).
  Red-first happening in the field without a rule making it.
- The genuine escape: the halt banner's blink, `sin(quant(t,2)*Math.PI*2)`,
  exactly 0 at every `t` from the first draft. Pure in `t` (smoke green), no
  discontinuity (no strip pop), sub-threshold for `motion`'s whole-frame
  delta. Found by hand, by accident. The cold session's own postmortem
  correctly called it a toolkit gap, not a discipline failure.
- Near-misses and friction: the HUD was first hand-rolled with
  `ctx.fillText` (silent `?strip=text` opt-out; caught by re-reading the
  template's kernel comment, never by an instrument); `build.js all` left
  1,110 PNGs / 52 MB in `frames/` unnoticed until the postmortem (figures
  re-derived from the transcript's own `ls`/`du` output, not from prose);
  one wrong-file read on the `nocap` sheet name; three `strip` runs
  overwrote one fixed output filename.
- Two instructions did not bind: SKILL.md step 4's "Delegate this to the
  `film-reviewer` agent" (the session reviewed inline — and shipped fine),
  and the film field report fired **by name only** — the session announced
  the step, then wrote a delivery note without the three bullets.

## Worth saying plainly

The cold session is the best single piece of evidence the project has that
the skill works as shipped: the docs alone carried a zero-context builder
through spec, build, three-axis review, export and delivery in one pass. The
two things it could not catch — an animation that never animated, and an
instrument silently narrowed by an authoring shortcut — are both now written
where the next builder reads, and both have their mechanical forms filed
with triggers rather than built in a hurry at the end of a mining session.
